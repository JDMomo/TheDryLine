The Dry Line

A run down an old toll railway. Keyboard or up to four controllers.

Controls and how a run works

How a run works

  • Every gate at the Junction is open from the start. Each line ends at a Warden.
  • The party carries three tokens in all (four with four players). Each token has a cut: pierce, arc, burst or ground.
  • At the start of a run every Warden gets a lock chart: three of the four cuts have a fare slot there, the fourth has none. The board in the Junction, the map (Tab) and each gate show the chart.
  • A charted fare slot opens only for a cut you carry when the fight starts. Three token hits punch a slot: the Warden loses 10% of its health, staggers and loses an attack. That token is then void.
  • Each extra player adds 60% to a Warden's health. Every Warden can be beaten with slashes alone.
  • Trials hold signal posts that teach new moves. Tokens come from four guarded plinths (one per line), two lost trunks (they open when the room is clear) and one ticket machine (30 scrip, then 45). The kiosk sells trinkets only.
  • A standpipe in the Junction and one before the last Warden each mend the party once. A Warden gives one more health pip, 40 scrip and a choice of one of three trinkets.
  • Punching a slot of a cut for the first time unlocks that cut's rare tokens for every later run. A run code (pause or run-over screen) replays the same world, chart and rewards: add it to the address as #CODE.
